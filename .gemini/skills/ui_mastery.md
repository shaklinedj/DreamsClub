# Skill: DreamsClub UI/UX Mastery

This skill guides the creation of high-fidelity, premium UI components for the DreamsClub application.

## Core Design Principles
- **Atmosphere**: Premium, modern, and engaging (Casino/Club vibe).
- **Typography**: Oswald for headings (bold, high impact), Roboto/Open Sans for body text.
- **Colors**: Deep purples, rich dark backgrounds, and vibrant gold or neon accents.
- **Interactivity**: Use subtle animations, hover effects, and rounded corners (typically 8dp-16dp).

## Component Guidelines

### Buttons
- Use `ElevatedButton` with the theme defined in `main.dart`.
- Favor rounded rectangles and subtle gradients.

### Cards
- Use `Card` or `Container` with decoration.
- Implement subtle shadows or glassmorphism effects where appropriate.

### Icons
- Use Material Icons primarily.
- For custom icons, use `ImageIcon` with assets declared in `pubspec.yaml`.

## Implementation Checklist
- [ ] Uses Material 3 components.
- [ ] Adheres to the color scheme in `lib/main.dart`.
- [ ] Typography matches the brand guidelines.
- [ ] Responsive layout tested on different screen sizes.
- [ ] Proper use of `SafeArea`.
